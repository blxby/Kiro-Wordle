# Tech rules

## Environment

- Windows 11 + **WSL Ubuntu**, g++ (C++17), GNU make. Edit in VS Code / Kiro.
- The web page is opened from the Windows browser at `http://localhost:8080` (WSL2 forwards localhost).

## Languages

- **C++ only** for all program logic: solver, server, tests, benchmark.
- **No Python anywhere.** No Node.js, no npm, no build tools for the web page.
- The web front end is plain **HTML + CSS + vanilla JavaScript** (no frameworks, no CDN libraries),
  served as static files by the C++ server.

## C++ style (Tony's preferences)

- Basic arrays and loops, `new[]`/`delete[]`, plain structs. **No `std::vector`, `std::map`,
  or other STL containers** in project code. `std::string` is fine.
- Follow the existing code style in `src/` (4-space indent, braces on the same line,
  one statement per line, descriptive names, short comments above blocks).
- No unnecessary extra function parameters. Keep functions short.
- No exceptions, templates, lambdas, `auto`, smart pointers, or classes with inheritance.
- Build JSON responses by hand with string concatenation (no JSON library).

## Allowed third-party code

- **cpp-httplib** (single header, MIT license) for the HTTP server only. Download one pinned
  release tag of `httplib.h` from https://github.com/yhirose/cpp-httplib into
  `third_party/httplib.h`, and note the version in the README. It needs `-pthread` when linking.
- Nothing else.

## Do not modify without asking Tony

- `src/trie.h`, `src/trie.cpp` (the core data structure, Tony's own work)
- `src/constraints.h`, `src/constraints.cpp`
- `src/baselines.*`, `bench/bench.cpp`, `tests/tests.cpp` (existing tests must keep passing)

If a task seems to need a change there, stop and ask instead.

## Build

- `make` builds everything. Targets: `solver` (terminal UI), `server` (web), `tests`
  (produces `run_tests`), `bench` (produces `run_bench`), `clean`.
- `-std=c++17 -Wall -O2` for `solver`, `server`, `bench`; `-g` for `tests`.
- Must compile with **zero warnings**.
- Run programs from the project root so `data/words.txt` and `web/` are found.

## Explaining new concepts

Tony is a second-year CS student (CSC 212: arrays, pointers, recursion, linked lists, stacks/queues).
When code uses something outside that (ANSI escape codes, HTTP, routes, query strings, JSON,
`fetch`, the DOM, CSS grid), add a 1-3 line comment at the first use that explains it plainly.
